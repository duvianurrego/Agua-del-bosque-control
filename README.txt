AGUA DEL BOSQUE CONTROL 4.0 — MVP DE PRUEBA

1. Abra index.html en un navegador moderno.
2. Registre clientes.
3. Registre ventas y producción.
4. Revise Dashboard, Inventario y Mapa/Rutas.
5. Los datos se guardan localmente en el navegador (localStorage).
6. Para pruebas multiusuario reales se debe conectar backend/base de datos, autenticación y mapas reales.

SIGUIENTE FASE RECOMENDADA:
- Base de datos PostgreSQL/Supabase.
- Usuarios y roles: Socio, Gerente, Ventas/Impulsadora, Domiciliario, Producción.
- Mapa real con coordenadas y geocodificación.
- Pedidos y estados de entrega.
- Cierre de caja y cartera.
- Inventario retornable/QR.
- Reportes y auditoría.
- Integración CCTV mediante enlaces/streams autorizados.
